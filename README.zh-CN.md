# OpenBridge

[![最新版本](https://img.shields.io/github/v/release/PredatorWoah/OpenBridge?sort=semver)](https://github.com/PredatorWoah/OpenBridge/releases/latest)
[![许可证: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

![手机上的 OpenBridge 拱桥亮起金色，电脑上正在浏览手机相册并下载照片](docs/images/screens.png)

**OpenBridge 是一款免费、开源的工具，用来在安卓手机和 Windows 电脑或 Mac 之间传文件。** 在手机上点一下太阳，电脑上就能看到手机；两边核对 6 位数字后配对，之后所有传输都经过加密的 Wi‑Fi 连接。文件只在你的两台设备之间流动：无需账号，不经云端，没有追踪。

## 为什么不用“手机连接”（Phone Link）？

微软的“手机连接”需要微软账号，主要照顾三星和荣耀，许多国产手机或没有谷歌服务的手机经常连不上。OpenBridge 不需要这些：

- 📱 **支持任何安卓 8.0 以上的手机**：小米、OPPO、vivo、一加、荣耀、realme、魅族等都可以，不依赖谷歌服务。
- 🔒 **加密且不经云端**：每个请求都走 TLS，配对时像蓝牙一样核对 6 位数字。没有服务器，没有账号。
- 📶 **自动发现**：同一 Wi‑Fi 下正在共享的手机会自动出现在电脑上，不用输入地址。
- 🗂️ **好用的文件浏览器**：缩略图、按名称/大小/类型排序、Ctrl 和 Shift 多选、整个文件夹下载、拖进窗口即可上传、新建文件夹。
- 🐘 **大文件没问题**：4 GB 以上的文件也能传。下载中断后会从断点继续；同一部手机重新配对后会自动接着传。
- 📋 **共享剪贴板**：把电脑剪贴板发到手机，或把手机剪贴板复制到电脑。
- 📺 **投屏控制（测试版）**：内置开源的 [scrcpy](https://github.com/Genymobile/scrcpy)，用鼠标键盘操作手机。
- 🛡️ **从不覆盖文件**：重名时自动改名为“photo 2.jpg”这样的名字。
- 🌏 **中文界面**：Windows 版会跟随系统语言显示简体中文。

## 下载与安装

从[最新版本](https://github.com/PredatorWoah/OpenBridge/releases/latest)下载：

1. **手机**：下载 `OpenBridge-<版本>.apk` 并打开安装。系统提示时，允许浏览器或文件管理器安装应用。部分国产系统会提示“风险应用”，选择“继续安装”即可。
2. **Windows**：下载 `OpenBridge-<版本>-Windows-Setup.exe` 并运行。它只为当前用户安装，不需要管理员权限，会在开始菜单和桌面添加快捷方式，也不需要另装 Java。不想安装的话，也可以下载 `OpenBridge-<版本>-Windows.zip`，解压后直接运行 `OpenBridge.exe`。
   - 应用暂未进行代码签名，如果出现“Windows 已保护你的电脑”，点“更多信息 › 仍要运行”。
   - 防火墙询问时，允许在“专用网络”上访问。
3. **Mac**：下载 `.dmg`，详见[英文说明](README.md#install-a-release)。

可以用版本页面的 `SHA256SUMS.txt` 校验下载的文件。

## 使用方法

### 通过 Wi‑Fi（推荐）

1. 手机和电脑连接同一个 Wi‑Fi（访客网络或开启了“AP 隔离”的网络可能无法连接）。
2. 在手机上打开 OpenBridge，选择共享**整部手机**（需要允许“所有文件访问权限”）或**某个文件夹**，然后**点一下太阳**。
3. 在电脑上，手机会出现在**附近的手机**中，点击它。也可以手动输入手机上显示的地址和端口，再点**配对**。
4. 两边都会显示 6 位数字。**只有数字一致时**才在手机上点**配对**。如果不一致，请点取消。
5. 配对成功后，太阳会变成金色。双击打开文件夹，选择文件后点**下载**；把文件拖进窗口即可上传；更多操作在 **⋯** 菜单里。

开启“后台共享”后，离开 OpenBridge 也会继续共享，通知栏里可以随时停止。

### 通过数据线

连接手机并解锁，下拉通知栏，点 USB 通知，选择**文件传输**。OpenBridge 会检测到手机并提供**在文件资源管理器中打开**，Windows 会像 U 盘一样显示手机。

### 投屏控制（测试版）

1. 只需设置一次：在手机上打开“设置 › 关于手机”，连续点 7 次**版本号**，然后在“开发者选项”中打开 **USB 调试**。部分手机（如小米）还需要打开“USB 调试（安全设置）”才能用鼠标操作。
2. 用数据线连接手机，在 OpenBridge 中点**投屏控制**。
3. 第一次使用时，手机会询问“是否允许 USB 调试？”，勾选“始终允许”，再点**允许**。

USB 调试会让受信任的电脑获得较大的手机权限，不用投屏时建议关闭。详见 [SECURITY.md](SECURITY.md)。

## 常见问题

- **电脑上看不到手机？** 确认手机上正在共享（太阳在转或通知栏有“正在共享”），两台设备在同一 Wi‑Fi，且 Windows 防火墙允许了 OpenBridge。Windows 会把新连接的 Wi‑Fi 默认设为“公用网络”，这时找不到手机：打开 设置 › 网络和 Internet › WLAN，选择“专用网络”。也可以直接输入手机上显示的地址（可以粘贴 `192.168.1.23:41987` 这样的格式）。
- **连接失败？** 如果电脑开着 VPN 或代理（如全局模式），请允许局域网流量或暂时关闭。
- **华为手机可以用吗？** 运行 EMUI 或鸿蒙 2 到 4 的华为手机可以。纯血鸿蒙（HarmonyOS NEXT）无法安装安卓应用，所以暂不支持。
- **会上传到云端吗？** 不会。OpenBridge 没有服务器，文件只在你的手机和电脑之间直接传输。
- **安全吗？** 所有 Wi‑Fi 通信都使用 TLS 加密，并在配对时固定手机的证书。完整说明见 [SECURITY.md](SECURITY.md)（英文）。

## 目前的不足

- Windows 版是测试版，暂未进行代码签名，首次运行时 SmartScreen 可能会提示。
- 上传中断后会重新上传该文件（下载可以断点续传）。
- 没有文件夹同步、备份或短信通知等功能。
- 投屏需要开启 USB 调试，并且只能通过数据线。
